# 라운드 타이머

참가자가 각자 준비해 온 제시문을 서로 바꿔 읽고 발표하는 스터디용 타이머입니다.
한 기기에서 화면을 함께 보며 쓰도록 만들었고, 서버 없이 브라우저만으로 동작합니다.

<https://skykhs3.github.io/round-timer/>

## 진행 방식

1. 참가자 이름과 제시문 제목을 입력합니다. 행 순서가 문제 번호이고, 화면에는 "문제 1. 제목" 형태로 표시됩니다.
2. "라운드 1 시작"을 누르면 읽기 타이머가 돌아갑니다. 이 시간에는 모두가 제시문을 읽고, 아직 아무것도 배정되지 않습니다.
3. 읽기 타이머가 끝나면 알람이 울립니다. "배정 뽑기"를 누르면 누가 어떤 문제를 받는지가 무작위로 정해지고, 발표 순서도 함께 정해집니다. 마음에 안 들면 다시 뽑을 수 있습니다.
4. 결과를 확인하고 "발표로 넘어가기" 뒤 "발표 시작"을 누르면 발표자 1인당 타이머가 돌아갑니다. 끝나면 알람이 울리고 "다음 발표자"로 넘어갑니다.
5. 라운드 2는 읽기 시간 없이 바로 배정을 뽑습니다(필요하면 "읽기부터 시작"도 가능). 라운드 1에서 받은 문제는 다시 받지 않도록 배정합니다.

## 규칙과 옵션

- 한 라운드에서 문제는 한 사람에게만 배정됩니다. 라운드 1과 2에서 같은 사람이 같은 문제를 받지 않습니다.
- "본인 제시문 제외" 옵션을 켜면 자기가 준비한 문제는 받지 않습니다. 이 옵션을 켜면 3명 이상, 끄면 2명 이상이어야 합니다.
- "발표할 문제의 번호 순으로 발표하기" 옵션(기본 켬)을 켜면 배정받은 문제의 번호가 곧 발표 순서입니다. 문제 N번을 발표하는 사람이 N번째로 발표합니다. 끄면 발표 순서를 따로 무작위로 뽑습니다.
- "발표 타이머 숨기기" 옵션을 켜면 발표 화면에서 타이머를 숨깁니다. 발표자가 직접 시간을 잴 때 씁니다. 발표 화면에서도 바로 켜고 끌 수 있습니다.
- 읽기 시간은 기본 20분, 발표자 1인당 시간은 기본 2분이며 설정에서 바꿀 수 있습니다. 타이머가 도는 중에도 "남은 시간 변경"으로 `3`(분), `1.5`(분), `3:30`(분:초) 형식으로 남은 시간을 바꿀 수 있습니다.

## 개발

빌드 없이 정적 파일만 사용합니다.

```sh
python3 -m http.server 8000   # http://localhost:8000
node --test                   # 배정 알고리즘 테스트
```
