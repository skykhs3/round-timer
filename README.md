# 라운드 타이머

참가자가 각자 준비해 온 제시문을 서로 바꿔 읽고 발표하는 스터디용 타이머입니다.
한 기기에서 화면을 함께 보며 쓰도록 만들었고, 서버 없이 브라우저만으로 동작합니다.

<https://skykhs3.github.io/round-timer/>

## 진행 방식

1. 참가자 이름과 제시문 제목을 입력합니다. 행 순서가 제시문 번호입니다.
2. "라운드 1 배정"을 누르면 제시문이 무작위로 배정됩니다. 제시문 k번을 받은 사람이 k번째로 발표합니다.
3. 읽기 타이머가 끝나면 알람이 울립니다. "발표로 넘어가기"를 누르면 발표 순서 표가 나옵니다.
4. 발표 순서를 확인한 뒤 "발표 시작"을 누르면 발표자 1인당 타이머가 돌아갑니다. 끝나면 알람이 울리고 "다음 발표자"로 넘어갑니다.
5. 라운드 2는 라운드 1에서 받은 제시문을 다시 받지 않도록 배정합니다.

## 규칙

- 한 라운드에서 제시문은 한 사람에게만 배정됩니다.
- 라운드 1과 2에서 같은 사람이 같은 제시문을 받지 않습니다.
- "본인 제시문 제외" 옵션을 켜면 자기가 준비한 제시문은 받지 않습니다. 이 옵션을 켜면 3명 이상, 끄면 2명 이상이어야 합니다.
- 읽기 시간은 기본 20분, 발표자 1인당 시간은 기본 2분이며 둘 다 설정에서 바꿀 수 있습니다.

## 개발

빌드 없이 정적 파일만 사용합니다.

```sh
python3 -m http.server 8000   # http://localhost:8000
node --test                   # 배정 알고리즘 테스트
```
